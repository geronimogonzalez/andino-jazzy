## Impresión

Dentro de los componentes impresos, realizamos algunas modificaciones con respecto al modelo original, eliminamos piezas que no utilizamos, y añadimos/creamos otras que son necesarias. las piezas que tenemos son:

* Base chasis: se necesitan dos, una superior y otra inferior. (para una siguiente actualizacion se pueden añadir algunos agujeros que debimos hacer posteriormente).
* soporte de camara (3 partes): este es el soporte original. (se puede modificar tambien el soporte en "C" para añadir agujeros correspondientes).
* suplemento de rueda: es un bloque que va entre la "rueda loca" y el chasis inferior, es para que mantenga la misma altura que con la rueda de los motores. (modificar correctamente agujeros).
* soporte de motores: este soporte fija mas fuertemente los motores, de manera de que queden correctamente alineados. (ver agujeros de sujecion al chasis).
* soporte de lidar (2 partes): este sirve para poder agarrar el lidar al "techo" del robot.



## Agujeros añadidos
