# PCB

En este documento se detalla tanto la descipcion de la placa de circuitos impresos (PCB), utilizada aqui, como su fabricacion.



## Descripción

Esta placa se construyo con el motivo de contrener tanto a los elementos electronicos necesarios como a los diversos modulos utilizados. Esto es para que esten todos estos componentes condensados en un solo lugar, de manera tambien de reducir el cableado.

## Construcción

Para la construccion realizamos primero el esquematico, en Kicad, luego de ahi pasamos al diseño del PCB. Para algunos componentes tuvimos que crear las "huellas" (Fontprint) a mano, con las medidas reales. Una vez se tiene el diseño correspondiente pasamos a la construccion mediante la tecnica del planchado.

Pasos:

1. Imprisión: se imprime el diseño en un papel fotografico con tinta de toner. Debe ser en escala 1:1 y se debe prestar atrencion de la cara de impresión (algunos prograsmas lo hacen automaticamente, de lo contrario se debe espejar el diseño).
2. Preparacion de placa: se corta la palca de cobre a la medida correspondiente, esto es mediante un cuter y una regla, haciendo cada vez pasadas mas profundas. Una vez cortada se deben limar los bordes y posteriormente se limpia la superficie de cobre con una lana de acero y detergente (debe quedar brillosa). Posteriormente se seca bien y se debe evitar tocar la superficie para no ensuciarla. 
3. Planchado: se coloca el papel cuidadosamente alineado a la placa y se doblan los bordes sobrantes para que quede firmemente agarrada en la posicion correspondiente. Se procesde a planchar serciorandose de cubrir toda la placa de manera pareja, para que se distribuya correctamente el calor.
4. Retiro del papel: se coloca la placa ya "transferida" en un resipiente con agua y se deja unos minutos hasta que el papel se ablande y se despeque. una vez asi, se retira cuidadosamente y se corrobora que donde deben ir las pistas haya toner, y donde no, se vea el cobre, sin papel.
5. Baño de acido: lo siguiente es sumergir la placa en acido para que "coma" el cobre que no va. Aveces se realiza antes de esto algun agujero de sugecion que lleve la placa, de manera que se pueda agarrar con un ganchito antes de colocarla en acido, y poder retirarla facilmente.
6. Limpieza: luego del acido se lava con agua para retirar restos de acido, pero cuidando de no levantar aun el toner.
7. Mecanizado: con la marca aun del toner se realizan los agujeros de sujhecion de los componentes, como tambien los demas agujeros mecanicos.
8. serigrafia: si se quiere añadir serigrafia se puede hacer con la misma tecnica de planchado, pero en la cara opuesta.
9. Limpieza: ahora si se lava de nuevo con una lana de acero, retirando el toner, restos de papel y acido, debiendo quedar de nuevo las pistas de cobre brillantes.
10. barnizado: finalmente, para proteger el cobre y para un posterior mejor soldado, se se aplica una capa de flux a la superficie de cobre.
