- **BUILING BRANCH** → claramente quedó de desarrollo original.

- Instalación genérica clonando el Andino original.

- Tampoco aparecen los alias `ttyUSB_ARDUINO` / `ttyUSB_LIDAR` que ahora forman parte de nuestra instalación.
- La documentación mezcla **presentación del proyecto**, **instalación**, **uso**, **simulación** y **contribución**.
